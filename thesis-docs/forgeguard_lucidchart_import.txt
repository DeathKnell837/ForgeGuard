HOW TO IMPORT INTO LUCIDCHART (3 EASY CLICKS):
--------------------------------------------------------------------------------
1. Log into your Lucidchart account (https://lucid.app).
2. Create a new blank document.
3. In the top menu, go to:
   File > Import Data > PlantUML  (OR Insert > Data > Mermaid)
4. Copy and paste the PlantUML code or Mermaid code below into the import box.
5. Click 'Generate' or 'Insert'. Lucidchart will automatically draw, arrange,
   and color-code your complete architectural diagram with editable cards and arrows!

You can also directly drag-and-drop the ready-made vector diagram into Lucidchart:
	hesis-docs/forgeguard_system_architecture.svg
